# AI School OS 제품 시연 가이드

이 문서는 로컬에서 **실제 회원가입·DB 저장·과제별 AI·학생 제출·교사 검토**를 확인하는 순서입니다. 랜딩의 20초 영상은 예시 데이터로 만든 제품 소개용 3D 애니메이션입니다. 영상 재생만으로 실제 서비스 기능이나 외부 AI 연결이 검증되지는 않습니다.

## 준비

README의 설치, 마이그레이션, 개발 서버 실행을 먼저 완료합니다. 샘플 데이터를 사용하려면 `npm run db:seed`를 실행하세요. 선생님 `teacher@example.com`과 학생 `student@example.com`의 개발 전용 비밀번호는 `SchoolDemo!2026`입니다. 공개 서비스에서 이 계정을 사용하지 않습니다.

선생님 창과 학생 창은 서로 다른 브라우저 프로필 또는 시크릿 창으로 엽니다. 같은 프로필의 탭은 세션 쿠키를 공유하므로 한 창에서 역할을 바꾸면 다른 탭의 로그인도 바뀝니다.

실제 AI 시연에는 `.env`의 `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL` 설정과 서버 재시작이 필요합니다. API 키가 없으면 과제 관리는 이용할 수 있지만 질문은 보낼 수 없습니다. E2E 테스트의 로컬 고정 응답은 실제 서비스에서 사용하지 않습니다.

## 회원가입부터 제출·검토까지

| 순서 | 행동 | 확인할 결과 |
| --- | --- | --- |
| 1 | 선생님 역할로 회원가입합니다. | 선생님 대시보드가 열립니다. |
| 2 | **내 클래스 → 클래스 만들기**에서 수업명과 과목을 저장합니다. | 새 클래스와 무작위 초대 코드가 표시됩니다. |
| 3 | 클래스의 **과제 등록**에서 제목·종류·마감일·설명·평가기준을 작성합니다. | 등록한 내용이 과제 상세에 표시됩니다. 첨부는 선택입니다. |
| 4 | 별도 창에서 학생 역할로 회원가입합니다. | 학생 대시보드가 열립니다. |
| 5 | **설정**에서 학교·학년·반을 저장하고 **내 클래스**에서 초대 코드를 입력합니다. | 클래스에 참여되고 해당 수업 과제가 보입니다. |
| 6 | **대시보드**에서 과제를 선택합니다. | 제목·설명·평가기준·마감일·D-Day를 확인할 수 있습니다. |
| 7 | AI에게 “이 과제는 무엇부터 시작하면 돼?”라고 질문합니다. | 설정한 외부 제공자가 현재 과제 문맥에 맞는 답변을 반환합니다. 답변 품질은 제공자와 모델에 따라 다릅니다. |
| 8 | 이어서 “오늘 30분만 쓸 수 있어”라고 질문합니다. | 이전 대화와 과제 마감일을 참고한 응답을 확인할 수 있습니다. |
| 9 | 과제 화면을 새로고침합니다. | 질문과 답변 기록이 다시 표시됩니다. |
| 10 | 다른 과제에서 AI 대화를 엽니다. | 앞 과제의 대화가 섞이지 않습니다. |
| 11 | 학생이 **제출 내용**을 작성하고 과제를 제출합니다. | 제출 상태가 검토 대기로 바뀌고 과제도 완료로 표시됩니다. |
| 12 | 선생님 창의 해당 과제 화면을 새로고침합니다. | 제출물 검토 영역에서 학생의 내용을 확인할 수 있습니다. |
| 13 | 선생님이 검토 결과와 피드백을 저장합니다. | 검토 완료 또는 수정 요청 상태가 저장됩니다. |
| 14 | 학생이 과제 화면을 새로고침합니다. | 검토 결과와 선생님 피드백을 확인할 수 있습니다. |

학생의 제출은 텍스트 결과를 저장하는 기능입니다. 점수 자동 산정은 제공하지 않으며, 선생님이 검토 결과와 피드백을 직접 기록합니다. 이미 열린 다른 사용자 탭의 상태는 실시간으로 바뀌지 않으므로 새로고침해서 확인합니다.

## 발표에서 보여줄 다른 흐름

- **우선순위:** 과제 마감일은 한국 날짜 기준입니다. 학생은 미완료 과제를 마감일순으로 확인하고, 지난 과제도 놓치지 않도록 목록에서 볼 수 있습니다.
- **즐겨찾기:** 과제 상세에서 즐겨찾기를 누르고 **과제 모아보기 → 즐겨찾기**에서 다시 찾습니다.
- **개인 일정:** 캘린더에서 오늘의 일정을 추가하면 학생 대시보드의 **오늘의 개인 일정**에도 표시됩니다. 개인 일정은 다른 사용자에게 공유되지 않습니다.
- **AI 사용량:** 학생 설정에서 오늘 사용 횟수와 제공자가 반환한 토큰 수를 확인합니다. FREE는 하루 10회, PRO는 하루 100회이며 한국 시간 자정에 일별 한도가 바뀝니다.
- **반응형:** 모바일에서 메뉴를 열어 과제와 캘린더로 이동합니다. 메인페이지에서는 스크롤 연출과 영상 재생/일시정지를 함께 확인합니다.

## 혼동하기 쉬운 상태

| 보이는 상태 | 확인할 내용 |
| --- | --- |
| 학생에게 과제가 없음 | 올바른 클래스 코드로 참여했는지, 그 클래스에 과제가 등록됐는지 확인합니다. |
| AI 연결이 필요함 | AI 환경변수 3개를 설정하고 서버를 재시작합니다. 샘플 계정 생성이 AI 키를 제공하지는 않습니다. |
| AI 요청 한도 도달 | 설정에서 사용량과 플랜을 확인합니다. E2E용 고정 응답을 실제 AI로 소개하지 않습니다. |
| 선생님에게 제출물이 아직 보이지 않음 | 선생님 과제 화면을 새로고침합니다. |
| 샘플 과제가 지난 과제로 표시됨 | 샘플 마감일은 2026-09-20 23:59(한국)로 고정되어 있습니다. 현재 날짜에 맞는 새 과제를 만들어 시연합니다. |
| 링크가 “페이지를 찾을 수 없어요”로 표시됨 | 로그인 역할과 클래스 소속을 확인합니다. 다른 수업의 과제와 첨부는 볼 수 없습니다. |

PRO 자동 공부계획·고급 일정 분석·파일 내용 분석·PG 결제는 현재 준비 중입니다. 자동 대시보드 추천으로 표현하지 말고, 과제 상세의 AI에 직접 질문하는 흐름을 보여주세요.
