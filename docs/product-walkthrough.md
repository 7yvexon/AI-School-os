# AI School OS 제품 시연 가이드

이 문서는 로컬에서 **회원가입 → 클래스 참여 → 과제별 AI 대화 → 학생 제출 → 선생님 검토** 흐름을 확인하는 순서입니다. 처음 실행한다면 [README의 빠른 시작](../README.md#빠른-시작)을 먼저 완료하세요.

랜딩은 오늘 할 일 보드와 과제·클래스·AI 도우미의 연결 구조를 보여주는 정적인 제품
미리보기입니다. 미리보기만으로 실제 계정 기능이나 외부 AI 연결이 검증되지는 않습니다.

## 시연 전 체크리스트

- [ ] `npm ci`, `npm run db:generate`, `npm run db:deploy`, `npm run db:seed` 완료
- [ ] 개발 서버가 `http://localhost:3000`에서 실행 중
- [ ] 실제 AI를 보여줄 경우 `.env`의 `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL` 설정 후 서버 재시작
- [ ] 교사 계정으로 가입할 경우 `.env`의 `TEACHER_INVITE_CODE`를 설정하고 개발 서버를 재시작
- [ ] 선생님 창과 학생 창을 서로 다른 브라우저 프로필 또는 시크릿 창으로 준비
- [ ] 샘플 마감일이 지났다면 시연용 과제를 새로 생성

### 샘플 계정

| 역할   | 이메일                | 개발 전용 비밀번호       |
| ------ | --------------------- | ------------------------ |
| 선생님 | `teacher@example.com` | `npm run db:seed` 출력값 |
| 학생   | `student@example.com` | `npm run db:seed` 출력값 |

샘플 클래스는 **2학년 탐구 수업**, 초대 코드는 `BSS-7FBB881CA2`입니다. 새 클래스 코드는 `BSS-` 뒤에 대문자 16진수 10자리가 붙습니다. `npm run db:seed` 실행 시 로컬 시연용 임시 비밀번호가 생성되어 터미널에 출력됩니다. 샘플 과제의 마감일은 `prisma/seed.ts`에 정의된 **2026-09-20 23:59(한국)**이며, 실행 시점에 따라 D-Day 또는 기한 지남으로 표시됩니다. 샘플 계정과 비밀번호는 공개 서비스에서 사용하지 마세요.

실제 AI 설정이 없으면 클래스·과제·제출 기능은 이용할 수 있지만 질문은 보낼 수 없습니다. E2E 테스트의 로컬 고정 응답은 실제 서비스에서 사용하지 않습니다.

## 회원가입부터 제출·검토까지

| 순서 | 행동                                                                                                                    | 확인할 결과                                                           |
| ---- | ----------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 1    | `TEACHER_INVITE_CODE`가 설정된 개발환경에서 교사 초대 코드를 입력해 회원가입하거나 샘플 선생님으로 로그인합니다.        | 선생님 대시보드가 열립니다.                                           |
| 2    | **내 클래스 → 클래스 만들기**에서 수업명과 과목을 저장합니다.                                                           | 새 클래스와 무작위 초대 코드가 표시됩니다.                            |
| 3    | 클래스의 **과제 등록**에서 제목·종류·마감일·설명·평가기준을 작성합니다. 필요하면 PDF·PNG·JPG·TXT 첨부파일을 추가합니다. | 등록한 내용과 첨부 링크가 과제 상세에 표시됩니다.                     |
| 4    | 별도 브라우저 창에서 학생 역할로 회원가입하거나 샘플 학생으로 로그인합니다.                                             | 학생 대시보드가 열립니다.                                             |
| 5    | **설정**에서 학교·학년·반을 저장하고 **내 클래스**에서 초대 코드를 입력합니다.                                          | 클래스에 참여되고 해당 수업의 과제가 보입니다.                        |
| 6    | 학생 **대시보드**에서 과제를 선택합니다.                                                                                | 제목·설명·평가기준·마감일·D-Day를 확인할 수 있습니다.                 |
| 7    | 과제 화면의 AI 사용 안내를 확인하고 동의한 뒤 AI에게 “이 과제는 무엇부터 시작하면 돼?”라고 질문합니다.                  | 동의 후 설정한 외부 제공자가 현재 과제 문맥에 맞는 답변을 반환합니다. |
| 8    | 이어서 “오늘 30분만 쓸 수 있어”라고 질문합니다.                                                                         | 이전 대화와 과제 마감일을 참고한 응답을 확인할 수 있습니다.           |
| 9    | 과제 화면을 새로고침합니다.                                                                                             | 질문과 답변 기록이 과제별로 다시 표시됩니다.                          |
| 10   | 다른 과제에서 AI 대화를 엽니다.                                                                                         | 앞 과제의 대화가 섞이지 않습니다.                                     |
| 11   | 학생이 **제출 내용**을 작성하고 과제를 제출합니다.                                                                      | 제출 상태가 `검토 대기`로 바뀌고 과제도 완료로 표시됩니다.            |
| 12   | 선생님 창에서 해당 과제 화면을 새로고침합니다.                                                                          | **제출물 검토** 영역에서 학생의 내용을 확인할 수 있습니다.            |
| 13   | 선생님이 검토 결과와 피드백을 저장합니다.                                                                               | `검토 완료` 또는 `수정 요청` 상태가 저장됩니다.                       |
| 14   | 학생이 과제 화면을 새로고침합니다.                                                                                      | 선생님 검토 결과와 피드백을 확인할 수 있습니다.                       |

학생의 제출은 텍스트 결과를 저장하는 기능입니다. 점수 자동 산정은 제공하지 않으며, 선생님이 검토 결과와 피드백을 직접 기록합니다. 검토 기록은 과제에 누적 보존되고 과제를 보관해도 제출물·AI 기록이 삭제되지 않습니다. 이미 열린 다른 사용자 탭의 상태는 실시간으로 바뀌지 않으므로 새로고침해서 확인합니다.

## 발표에서 보여줄 다른 흐름

- **우선순위**: 과제 마감일은 한국 날짜 기준입니다. 학생은 미완료 과제를 마감일순으로 확인하고, 지난 과제도 목록에서 확인할 수 있습니다.
- **즐겨찾기**: 과제 상세에서 즐겨찾기를 누른 뒤 **과제 모아보기 → 즐겨찾기**에서 다시 찾습니다.
- **개인 일정**: 캘린더에서 오늘의 일정을 추가하면 학생 대시보드의 **오늘의 개인 일정**에도 표시됩니다. 개인 일정은 다른 사용자에게 공유되지 않습니다.
- **AI 사용량**: 학생 설정에서 오늘 사용 횟수와 제공자가 반환한 토큰 수를 확인합니다. FREE는 하루 10회, PRO는 하루 100회이며 한국 시간 자정에 일별 한도가 바뀝니다.
- **AI 개인정보 관리**: 학생 설정에서 AI 사용 동의를 철회하거나 저장된 과제별 AI 대화 기록을 삭제할 수 있습니다. 외부 제공자가 이미 수신한 데이터의 삭제는 제공자 정책을 확인해야 합니다.
- **클래스 관리**: 교사 클래스 화면에서 초대 코드를 재발급하면 이전 코드는 즉시 무효화됩니다. 학생 목록에서 특정 학생을 제외할 수 있으며, 제외된 학생의 기존 제출·검토 기록은 보존됩니다.
- **반응형**: 390px 정도의 모바일 폭에서 메뉴를 열어 과제와 캘린더로 이동합니다. 메인페이지에서는 오늘 할 일 보드와 과제 도우미 예시가 한 열로 정리되는지 확인합니다.

## 상태별 확인 방법

| 보이는 상태                               | 확인할 내용                                                                                   |
| ----------------------------------------- | --------------------------------------------------------------------------------------------- |
| 학생에게 과제가 없음                      | 올바른 클래스 코드로 참여했는지, 해당 클래스에 과제가 등록됐는지 확인합니다.                  |
| AI 연결이 필요함                          | AI 환경변수 3개를 설정하고 서버를 재시작합니다. 샘플 계정 생성이 AI 키를 제공하지는 않습니다. |
| AI 요청 한도 도달                         | 설정에서 사용량과 플랜을 확인합니다. E2E용 고정 응답을 실제 AI로 소개하지 않습니다.           |
| 선생님에게 제출물이 아직 보이지 않음      | 선생님 과제 화면을 새로고침합니다. 다른 탭에 실시간 푸시는 하지 않습니다.                     |
| 샘플 과제가 지난 과제로 표시됨            | `prisma/seed.ts`의 샘플 마감일을 확인하고, 시연 날짜에 맞는 새 과제를 만듭니다.               |
| 링크가 “페이지를 찾을 수 없어요”로 표시됨 | 로그인 역할과 클래스 소속을 확인합니다. 다른 수업의 과제와 첨부는 볼 수 없습니다.             |

## 시연 후 확인할 것

1. 학생 화면에서 제출 상태와 선생님 피드백이 보이는지 확인합니다.
2. 선생님 화면에서 학생별 완료 현황과 검토 상태가 반영됐는지 확인합니다.
3. 학생 설정에서 AI 사용량·토큰 수와 프로필이 저장됐는지 확인합니다.
4. 캘린더의 개인 일정이 학생 대시보드에만 표시되는지 확인합니다.
5. 다른 클래스의 학생 계정으로 과제·첨부·AI API에 접근할 수 없는지 확인합니다.

PRO 자동 공부계획·고급 일정 분석·파일 내용 분석·PG 결제는 현재 준비 중입니다. 자동 대시보드 추천으로 표현하지 말고, 과제 상세의 AI에 직접 질문하는 흐름을 보여 주세요.
